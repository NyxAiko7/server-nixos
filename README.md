Базовая настройка домашнего сервера на NixOS.

### 📦 Что настроено на сервере:
*   **NixOS** — операционная система с декларативной конфигурацией.
*   **Samba** — сетевая папка для обмена файлами.
*   **Jellyfin** — медиасервер для просмотра аниме и фильмов.
*   **Grafana + Prometheus** — система мониторинга состояния CPU, RAM и дисков.
*   **NetBird** — защищенная VPN-сеть для удаленного доступа.
